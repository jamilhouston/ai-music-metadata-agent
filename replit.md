# Replit setup

This project runs as a Streamlit app.

## Run

The configured workflow starts:

```text
streamlit run app.py --server.port 5000 --server.address 0.0.0.0
```

The app uses the `OPENAI_API_KEY` Replit Secret for AI analysis. The demo is public and requires no access code. Keep upload permission, privacy disclosures, and usage limits in place.
